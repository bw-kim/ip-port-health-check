# IP 포트 헬스체크

`실행.bat`을 더블클릭하면 로컬 대시보드가 열립니다. Python 3 표준 라이브러리만 사용합니다.

- IP/호스트, 검사할 TCP 포트, 분 단위 검사 주기를 설정할 수 있습니다.
- 기본 주요 포트를 즉시 검사하고 설정한 주기로 반복합니다.
- 열린 포트와 응답 없는 포트 수를 요약해 보여줍니다.
- 열린 포트가 발견되면 인지하거나 포트가 닫힐 때까지 비프음이 반복됩니다. `비프음 제외 포트`에 추가한 포트만 소리를 내지 않으며, 점검과 이력 기록은 그대로 수행합니다.
- 열린 포트가 하나라도 있으면 대시보드에 빨간 점멸 경보를 표시합니다. 최근 점검에서 열린 포트가 모두 닫히면 경보가 사라집니다.
- `인지`를 누르면 현재 경보의 점멸과 소리가 멈춥니다. 같은 포트 상태가 이어지는 동안은 다시 울리지 않고, 새 열린 포트가 생기면 다시 알립니다.
- `중지`를 누르면 반복 검사를 멈춥니다.
- 각 검사 결과는 같은 폴더의 `history.csv`에 자동으로 누적 저장되며, 대시보드에서 과거 이력을 다시 불러옵니다.
- `CSV 파일`을 누르면 누적 이력을 내려받을 수 있습니다.

포트 응답 없음은 포트 닫힘 또는 네트워크/방화벽 차단을 의미할 수 있습니다. 검사 권한이 있는 대상에 사용하세요.
